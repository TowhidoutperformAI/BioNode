## 🌱 What is BioNode?

**BioNode** is an AIoT-powered BioCNG micro-refinery designed to convert
locally available **water hyacinth biomass** into purified, compressed
BioCNG directly at the point of use.

Instead of transporting fuel across a long supply chain, BioNode brings
the production process closer to where the fuel is needed.

> **Free local feedstock → Autonomous processing → 200-bar BioCNG**
